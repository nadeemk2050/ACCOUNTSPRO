3 · Automatic Rules & Validation

Date, Dr Ledger, Cr Ledger and Amount are mandatory.
Both ledgers must exist in masters (party, expense, cash / bank, capital, asset, income).
A journal voucher must stay balanced — the importer posts the same amount on both sides.
For multi-leg journals repeat the same Voucher No + Date; the rows are merged into one voucher.
Duplicate voucher numbers already in the system are quarantined.
Dates inside the locked period are rejected.
Foreign currency rows need a valid exchange rate.
Tally XML journal vouchers are accepted on the same screen.
