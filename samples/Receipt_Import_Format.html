3 · Automatic Rules & Validation

Date and Amount are mandatory; amount must be greater than 0.
Received From (customer / party) must exist in masters — otherwise the row waits in Solution Centre.
Received In must be a Cash / Bank ledger of the company.
Duplicate voucher numbers already in the system are quarantined (auto-renumber or skip).
Same Voucher No + Date on several rows = one voucher with multiple givers (multi-split collection).
Foreign currency rows need a valid exchange rate.
Dates inside the locked period are rejected.
Tally XML receipt vouchers are accepted on the same screen.
Tip: Inside the app open Management Hub → Import Receipt → Instructions & Templates and press Download Standard (.xlsx) for a ready-made file with these exact headers.
